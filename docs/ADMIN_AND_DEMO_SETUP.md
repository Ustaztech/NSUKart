# Administrator and demo catalogue setup

1. Sign up at https://ustaztech-nsukart.vercel.app/signup with an email address you own and a unique strong password. Never use shared/default admin credentials.
2. In a trusted server environment with your Supabase service role key loaded, run `node --env-file=.env.local scripts/provision-admin.mjs YOUR_EMAIL`. **Do not run this command with secrets in a browser or client app.**
3. Log in and enrol TOTP MFA at `/account/security`. Admin routes require an AAL2 session.
4. Apply migration `supabase/migrations/202610270004_demo_catalogue.sql` after earlier migrations.
5. Visit `/admin/demo` and create sample listings; they have zero stock and are clearly marked DEMO — NOT FOR SALE.
6. Remove the demo catalogue from `/admin/demo` when real listings are available. This action deletes only tagged demo products and the demo store. It may fail safely if related records exist.

No actual administrator account or password is committed or generated by this repository update. Prices and products are illustrative, not genuine seller offers. Live availability, Supabase Auth, Resend email delivery, Paystack payments, and hosted RLS must be tested separately prior to representing the marketplace as production certified.
